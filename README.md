# SyntecxHub Project 2 — Website Traffic Analysis

## Project Overview

This project analyzes website traffic data to understand user behavior, traffic sources, engagement, conversions, and page performance.

The project was completed using Excel for data preparation and analysis and Power BI for interactive dashboard visualization.

## Objective

The main objectives of this project are to:

- Analyze website users and sessions
- Compare different traffic sources
- Measure bounce rate and user engagement
- Analyze conversion rates and goal completions
- Identify high- and low-performing pages
- Track website traffic and conversions over time
- Build an interactive Power BI dashboard

## Tools Used

- Microsoft Excel
- Power BI
- GitHub

## Dataset

The dataset contains website traffic information from January to June 2025.

Key fields include:

- Date
- Traffic Source
- Page
- Users
- Sessions
- Bounce Rate
- Average Session Duration
- Pages per Session
- Goal Completions
- Conversion Rate

## Data Cleaning

The dataset was cleaned before analysis by:

- Removing duplicate records
- Handling missing traffic source values
- Handling missing page values
- Replacing missing session-duration values
- Formatting percentages and numerical fields
- Preparing the dataset for Power BI analysis

## Key Performance Indicators

The dashboard includes:

- Total Users
- Total Sessions
- Average Bounce Rate
- Average Session Duration
- Total Goal Completions
- Average Pages per Session
- Overall Conversion Rate

## Analysis Performed

### Traffic Source Analysis

Traffic sources were compared using:

- Users
- Sessions
- Conversion Rate
- Goal Completions
- Average Session Duration

### Page Performance Analysis

Website pages were analyzed based on:

- Total Users
- Total Sessions
- Average Bounce Rate
- Goal Completions

### Monthly Analysis

Website performance was analyzed across January–June 2025 using:

- Monthly Users
- Monthly Goal Completions

## Power BI Dashboard

The interactive dashboard includes:

- KPI cards
- Conversion Rate by Traffic Source
- Goal Completions by Traffic Source
- Users by Page
- Bounce Rate by Page
- Monthly Website Users
- Monthly Goal Completions
- Users by Traffic Source
- Traffic Source slicer
- Page slicer
- Date slicer
